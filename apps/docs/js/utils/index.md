# @xxkatt/utils

JavaScript / TypeScript 工具包，提供 ESM 导出和 TypeScript 类型声明。

## 工具函数

| 函数                    | 用途                                          |
| ----------------------- | --------------------------------------------- |
| [uuid](./uuid)          | 生成 UUID v4，支持保留横杠和添加前缀          |
| [randomId](./random-id) | 使用加密安全随机数生成指定长度、指定基数的 ID |

首次使用请先阅读[快速开始](/guide/getting-started)。所有函数均从 `@xxkatt/utils` 的公共入口导入。
