## 🚀 特性

- 🦾 **类型齐全**：使用 TypeScript 编写，提供类型声明与参数提示。
- 💫 **零依赖**：无运行时依赖，只安装工具库本身。
- ⚡️ **按需打包**：提供 ESM 导出，支持 Tree-shaking。
- 🌎 **框架无关**：支持 Node.js 24+ 和现代浏览器，可搭配不同的前端框架使用。

## 📦 安装

```sh
# npm
npm install @xxkatt/utils

# pnpm
pnpm add @xxkatt/utils

# yarn
yarn add @xxkatt/utils
```
